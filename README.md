# CounterFlame Assistant

A standalone Android training companion project.

## Features
- ESP demo: sample markers rendered only inside this app.
- AIM practice: sensitivity slider and a manual training counter.
- Training: adjustable practice crosshair.

## Safety and scope
This app does not inspect, modify, inject into, or overlay CounterFlame. It does not reveal opponents through walls or automate aiming in matches. It is a standalone practice/settings companion.

## Build
Open this folder in Android Studio (Hedgehog or newer), allow Gradle sync, then choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

Package: `com.example.counterflameassistant`
Min Android: 6.0 (API 23)
Target SDK: 35
